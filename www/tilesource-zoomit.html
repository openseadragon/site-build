example: integrating with ZoomHub (formerly zoom.it) tiles

ZoomHub, formerly zoom.it, provides a simple service-based way of loading images and serving tiles. The ZoomHub service is based on the DZI format, and all old zoom.it images keep working.

OpenSeadragon can render the DZI tiles and provide you all the features you can only get with OpenSeadragon.

To get started:

  1. Upload your image or PDF at https://zoomhub.net, or paste a link to one.
  2. You can then get the info you need about the resulting image by going to
    https://api.zoomhub.net/v2/assets/<YOUR_IMAGE_ID>. Its image.dzi has the DZI’s URL, size, tile size, overlap and format.
  3. See below for how to format that information for OpenSeadragon.

For more advanced use, see the ZoomHub API.

Pulling Tiles From ZoomHub

If you are pulling image tiles from ZoomHub, please respect the copyright of the image creator and the policies of the ZoomHub service.

Example Inline Configuration for Rendering DZIs Hosted at ZoomHub

Configuration is done via the tileSources option (or programmatically). Given inline, OpenSeadragon need not fetch the DZI before it can show the image. The Url is the DZI’s own with _files/ in place of .dzi. The tiles come from another domain, so set crossOriginPolicy as well: ZoomHub serves them with the CORS headers the WebGL drawer needs. 

OpenSeadragon({
    ...
    crossOriginPolicy: "anonymous",
    tileSources:   [{ 
        Image:  {
            xmlns: "http://schemas.microsoft.com/deepzoom/2009",
            Url: "https://cache.zoomhub.net/content/WwI0_files/",
            TileSize: "254", 
            Overlap: "1", 
            Format: "jpg", 
            Size: { 
                Width: "5816",
                Height: "3961"
            }
        }
    }]
    ...
});
